Introduction to Data

Start with a question students can relate to.

Classroom situation

Your school wants to select the student of the month. What information will the teacher need?

📘 Marks

All these facts are data. We analyse them to make a decision.

Why is data important?

🎓 Education

Schools analyse marks and attendance to identify learning needs.

🏦 Banking

Banks store account and transaction details to verify withdrawals.

🌦️ Weather

Satellite data helps forecast heavy rain and cyclones.

🛍️ Business

Sales data helps identify customer demand and plan discounts.

🗳️ Elections

Voting data is counted to declare election results.

🔎 Search engines

Large amounts of web data are analysed to return search results.
Remember: Data by itself may not give a conclusion. It must be collected, processed and analysed to support decision-making.
02

Types of Data

Two broad categories based on format.

A

Structured Data

Data organised in a well-defined format, usually rows and columns. Each column represents an attribute and each row represents a record.

Roll No.NameMark
1Anu92
2Ravi85
3Meena90
Examples: Spreadsheet, student database, inventory table.
B

Unstructured Data

Data that does not follow a fixed row-and-column structure or predefined format.

📷 Images
🎥 Videos
✉️ Emails
💬 Social posts
Examples: Web pages, documents, books, audio/video files, social media messages.

Compare them

Structured dataUnstructured data
Organised formatNo fixed format
Usually rows and columnsMay contain text, image, audio or video
Easy to search using defined fieldsMore difficult to organise and analyse
Example: Excel marksheetExample: A video or email body
Metadata = data about data.
Email metadata: subject, recipient, attachment. Image metadata: file size, image type (JPEG/PNG), resolution.
Ask the class – identify the type:
1. Excel attendance sheet – Structured.
2. A video recorded on a phone – Unstructured.
3. A table of library books – Structured.
4. A social media comment – Unstructured.
03

Data Collection

Gathering data from appropriate sources before processing.

Definition: Data collection means identifying already available data or collecting data from appropriate sources.

Grocery shop example

Situation 1

Sales written in a diary/register.

Action: Enter into a spreadsheet.
Situation 2

Sales already in a CSV file.

Action: Import the digital data.
Situation 3

No sales data recorded.

Action: Develop software to collect it.

Other real-life data collection examples

  • Hospitals collect patient and treatment details.
  • Shopping malls collect purchase data.
  • Social media posts and messages can be analysed to understand public opinion.
  • World Bank and IMF collect economic data for forecasts.
Key idea: First find out whether the data already exists. If it does, retrieve or digitise it. If not, create a suitable method to collect it.

File processing and DBMS

File processing

Data is stored in separate files. Programs add, modify, delete or process file contents.

DBMS

Database Management System helps manage data in databases and overcome several limitations of file-based processing.

Think: Is it necessary to store data in files before processing? In many systems, data is collected and stored so it can be retrieved, checked, reused and processed reliably. Some systems may also process data streams as they arrive.

06

Statistical Techniques for Data Processing

Summarise data and understand its characteristics.

Statistics helps us describe a large set of values using a few meaningful measures.

A. Measures of Central Tendency

These give a single value that represents the centre or typical value of a data set.

Mean

Average of all values.

Sum ÷ Count

Median

Middle value after sorting.

Middle position

Mode

Value occurring most often.

Highest frequency
Worked example: Data = 10, 20, 20, 30, 40
Mean = (10+20+20+30+40) ÷ 5 = 24
Median = 20 (middle value)
Mode = 20 (appears twice)

Enter numbers separated by commas. Try the example above or the textbook height data.

Mean, median, mode and range will appear here.

B. Measures of Variability (Dispersion)

These show how spread out or varied the values are. Two data sets may have the same mean or median but different levels of spread.

Range

Difference between the maximum and minimum values.

Range = Maximum − Minimum

Example: 10, 20, 30, 40, 50 → 50 − 10 = 40.

Standard Deviation

Measures how far values are spread around the mean. It uses every value in the data set.

σ = √[ Σ(xᵢ − x̄)² / n ]

Smaller SD = values are closer to the mean. Larger SD = values are more spread out.

Standard deviation: six steps

1
Calculate the mean of the data.
2
Subtract the mean from each value: (xᵢ − x̄).
3
Square each difference: (xᵢ − x̄)².
4
Add all squared differences.
5
Divide the sum by the number of values (n).
6
Take the positive square root.
Textbook example: Heights = 90, 102, 110, 115, 85, 90, 100, 110, 110 cm.
n = 9; sum = 912; mean = 912/9 = 101.33 cm.
Median = 102 cm; Mode = 110 cm; Range = 115 − 85 = 30 cm.
Sum of squared deviations ≈ 938.00.
Variance = 938/9 = 104.22.
Standard deviation = √104.22 ≈ 10.2 cm.
Outlier: An exceptionally large or small value compared with the other values. Mean can be affected by outliers. Median is generally less sensitive to outliers.

Numerical challenge 1

Find mean, median, mode and range: 4, 6, 6, 8, 11.

Mean = 35/5 = 7. Median = 6. Mode = 6. Range = 11 − 4 = 7.
Numerical challenge 2

Find the mean and range: 12, 15, 18, 20, 25.

Mean = 90/5 = 18. Range = 25 − 12 = 13.
Numerical challenge 3

Find the median: 9, 3, 7, 5, 1, 11.

Sorted data: 1, 3, 5, 7, 9, 11. There are 6 values. Median = (5 + 7)/2 = 6.

08

Textbook Exercise – Answers

Answers to the exercise questions visible in your uploaded textbook pages (1–10).

Use “Show answer” after students attempt each question. Answers are model responses; for Q10, the dataset is illustrative because the exercise asks students to create one.

Q1. Identify data required to be maintained to perform the following services.

Show answer
(a) Declare exam results and print e-certificates: Student name, roll number, registration number, class, subject-wise marks, total marks, grade, result status, exam year and certificate ID.
(b) Register exhibition participants and issue biometric ID cards: Participant name, age, institution, contact details, registration number, photograph, biometric data (as authorised), event details and ID-card number.
(c) Search for an image by a search engine: Search keywords, image title, tags/description, file format, dimensions, source webpage/URL and indexed image content.
(d) Book an OPD appointment: Patient name, age, contact details, patient/registration ID, hospital, department, doctor, preferred date/time, appointment number and relevant booking details.

Q2. A school with 500 students wants to identify merit-cum-means scholarship beneficiaries: above 75% for two consecutive years and family income below ₹5 lakh per annum. What data is needed?

Show answer
Maintain student name, admission/roll number, class, marks and percentage for each of the two consecutive academic years, family annual income, income certificate details and eligibility status. Filter students satisfying percentage > 75% in both years AND annual family income < ₹5,00,000.

Q3. Briefly describe data processing steps to be taken by the beneficiary to prepare the list of schools.

Show answer
Input: Collect school details and beneficiary/student records, including marks for two years and family income.
Processing: Check completeness and correctness; calculate percentages if needed; filter students with more than 75% in both years and family income below ₹5 lakh; prepare the eligible list.
Output: A list/report of eligible scholarship beneficiaries with student details.

Q4. Identify the type of data being collected/generated.

Show answer
(a) Recording a video – Unstructured data.
(b) Marking attendance by a teacher – Structured data when entered in an attendance register/table.
(c) Writing tweets – Unstructured data.
(d) Filling an application form online – Structured data because information is entered into predefined fields.

Q5. Temperatures for 7 days: 34, 34, 27, 28, 27, 34, 34. Find average temperature, range and standard deviation.

Show answer
Sum = 218; n = 7.
Mean = 218/7 = 31.14°C (approx).
Range = 34 − 27 = 7°C.
Standard deviation (population formula used in the textbook):
Squared deviations sum ≈ 73.7143.
Variance = 73.7143/7 ≈ 10.5306.
SD = √10.5306 ≈ 3.25°C.

Q6. A teacher wants to analyse results. Choose the statistical technique with justification.

Show answer
(a) Compare division secured by students in Class XII A and XII B where class strength is equal: Mean, to compare average performance of the two classes. If variation is also required, compare standard deviation.
(b) Compare class performance across five unit tests from July to November: Mean marks/average for each test, to compare average performance across the five months. Standard deviation can additionally show consistency.

Q7. Annual day: identify parents who are alumni of the same school.

Show answer
(a) Use Mode to identify the most frequently occurring school/alumni school value in the parent records. To count students whose both parents are alumni of this school, compare both parents’ school-history fields for each student and count matching cases.
(b) Use Range to find the difference between the maximum and minimum parent ages. Use standard deviation if the overall spread of ages is required.

Q8. Select an anchor from 42 students based on singing, writing and monitoring skills.

Show answer
(a) Use a survey / structured assessment form or direct observation to collect skill information from all 42 students.
(b) Represent each student's skills as structured data in a table, for example: Student ID, singing score, writing score and monitoring score (using a consistent rating scale). Compare the scores to select a suitable student.

Q9. Differentiate between structured and unstructured data with one example.

Show answer
Structured data: Organised in a predefined format, usually rows and columns. Example: Student marksheet.
Unstructured data: Does not follow a fixed row-and-column format. Example: Video, photograph or email body.

Q10. Canteen analysis: compare purchase and sale prices of fruit juice and biscuits; compare sales of fruit juice, biscuits and samosa; find variation in sale price of fruit juices of different companies for same quantity.

Show answer and sample dataset
Sample dataset (illustrative):
Item / brandPurchase price (₹)Sale price (₹)Units soldQuantity
Fruit juice A152080200 ml
Fruit juice B172265200 ml
Biscuits810100Pack

(a) Purchase vs sale price: Fruit juice A profit per unit = ₹20−₹15 = ₹5. Biscuits profit per pack = ₹10−₹8 = ₹2.
(b) Compare sales: Biscuits 100 units, samosa 90, fruit juice A 80 (or combine juice brands = 145). Biscuits are highest among the individual listed rows; total juice sales across brands = 145.
(c) Variation in same-quantity juice prices: Sale prices are ₹20 and ₹22 for 200 ml. Range = ₹2. Mean sale price = ₹21. This illustrates the comparison; students may use actual canteen prices.
